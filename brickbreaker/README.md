# BrickBreaker CUBED

A brick breaker game with a twist, based on [BrickBreaker](https://github.com/CodingTrain/BrickBreaker)
by the Coding Train.

Open `index.html` in a browser, or serve the folder:

```bash
npx http-server brickbreaker -p 8080
```

| File | What it does |
| --- | --- |
| `sketch.js` | Setup, draw loop, levels and input |
| `ball.js` | Ball movement and bouncing |
| `paddle.js` | Paddle movement |
| `brick.js` | A single brick |
| `libraries/` | Vendored p5.js, p5.dom and p5.sound |
